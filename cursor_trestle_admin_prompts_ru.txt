ПРОМПТЫ ДЛЯ CURSOR
РЕАЛИЗАЦИЯ АДМИНИСТРАТИВНОЙ ПАНЕЛИ НА TRESTLE (RUBY ON RAILS)

==================================================
ЭТАП 0. БАЗОВАЯ ИНИЦИАЛИЗАЦИЯ АДМИНКИ
==================================================

Цель:
Подключить Trestle и подготовить проект к расширяемой административной панели.

Промпт для Cursor:

У нас есть существующий Ruby on Rails проект интернет-магазина.
Необходимо реализовать административную панель на базе Trestle.

Задачи:
1. Установить и сконфигурировать Trestle.
2. Создать модель AdminUser для доступа в админку.
3. Реализовать роли: admin, content_manager, marketer.
4. Ограничить доступ к админке и разделам по ролям.
5. Использовать best practices Rails, выносить общую логику в concerns.
6. Не реализовывать фронтовую авторизацию, только админскую.

==================================================
ЭТАП 1. КАТАЛОГ И БАЗОВЫЕ СПРАВОЧНИКИ
==================================================

Цель:
Создать базовые сущности каталога для управления через админку.

Промпт для Cursor:

Создай модели каталога для админ-панели.

Модели:
- Category (id, name, parent_id, position, is_large, active)
- Product (id, name, sku, category_id, active)
- Collection (id, name, active)

Требования:
- Category поддерживает неограниченную вложенность (self-referencing).
- Поле position управляет порядком.
- Реализовать Trestle-ресурсы для всех моделей.
- Для категорий нужен древовидный вид.
- Добавить базовые валидации.
- Сгенерировать миграции, модели и админ-интерфейсы.

ЭТАП 2. УПРАВЛЕНИЕ ГЛАВНОЙ СТРАНИЦЕЙ
==================================================

Цель:
Реализовать гибкое управление контентом главной страницы.

Промпт для Cursor:

Реализуй управление главной страницей в админке.

Создай модели:
- HomeSlider (title, image, format, position, active, starts_at, ends_at)
- HomeBlock (key, title, active, limit, source_type, position)

Требования:

- Управление порядком через position.
- Валидация изображений (формат/размер — заглушка).
- Реализовать Trestle-ресурсы с фильтрами и scope.
