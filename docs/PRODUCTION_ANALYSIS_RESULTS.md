## Варианты получения продуктов

### 1. HTML парсинг (приоритет 1)
**Статус:** ✅ Все категории имеют URL  
**Метод:** `CategoryProductsFetcher.fetch(category.url)`  
**Ожидаемый результат:** Высокий, так как все категории имеют URL

### 2. API по ID категории (приоритет 2)
**Статус:** ✅ 537 категорий имеют числовые ID  
**Метод:** `IkeaApiService.search_products_by_category(category_id)`  
**Ожидаемый результат:** Средний-высокий, зависит от валидности ID

### 3. API по названию категории (приоритет 3)
**Статус:** ✅ Все категории имеют название  
**Метод:** `CategoryProductsSearchService.search(category, strategies: [:api_by_category_name])`  
**Ожидаемый результат:** Средний, может вернуть продукты из других категорий
