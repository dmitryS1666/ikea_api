
# Сводное Техническое Задание

## 1. Хлебные Крошки (Breadcrumbs)

### Общие требования:
- Хлебные крошки должны отображать иерархию каталога, но не повторять структуру URL (если URL содержит фильтры).
- Последний элемент хлебных крошек должен совпадать с H1 SEO-страницы.
- Все элементы, кроме последнего, должны быть кликабельными.
- Хлебные крошки должны обновляться автоматически при изменении SEO-страницы.

### Структура:
1. **Для товаров:**  
   Главная → Каталог → Категория → Подкатегория → Товар  
   Пример: Главная → Каталог → Садовая мебель → Садовые стулья → Стул Название стула

2. **Для фильтров:**  
   Главная → Каталог → Категория → Подкатегория → Статичная страница фильтра  
   Пример: Главная → Каталог → Садовая мебель → Садовые стулья → Деревянные садовые стулья

### Технические требования:
- **Микроразметка Schema.org (JSON):**
  ```json

  {

    "@type": "BreadcrumbList",
    "itemListElement": [
      {

        "item": "https://site.ru/"
  ```

## 2. Функциональные требования к главной странице

### Ключевые блоки:
1. **Главный слайдер:**
   - Поддержка форматов WP, WPM.
   - Возможность управления через админку.
   - Изменение размеров слайдера (например, 3 баннера).

2. **Блоки товарных рекомендаций:**
   - Хиты продаж, новинки, и персональные рекомендации.
   - Могут быть включены/отключены в админке, с настройкой порядка категорий и товаров.

3. **Популярные категории:**
   - Отображение с иконками/изображениями.
   - Возможность настройки категорий через админку.

4. **Адаптивность:**
   - Все элементы должны быть адаптивными для разных устройств.

## 3. SEO-оптимизация

### Основные требования:
1. **Метаданные:**
   - Редактирование мета-тегов (title, description, H1) через админку для каждой страницы.
   - Автоматическая подстановка данных о товаре (например, SKU, цена, категория).

2. **Заголовки h1:**
   - Каждый товар и категория должны иметь заголовок h1, который можно редактировать вручную.

3. **Атрибуты изображений:**
   - Поддержка атрибутов alt и title для изображений.
   - Конвертация в форматы WebP, WebM.
   - Поддержка lazyload и srcset.

4. **Микроразметка Schema.org:**
   - Использование микроразметки для товаров и категорий с обязательными полями: name, description, price.

## 4. Технические SEO требования

### Стандарты индексации:
- Сайт должен поддерживать динамическую генерацию страниц с возможностью их индексации.
- Требования к URL: использование только латиницы, дефисы вместо подчеркиваний, отсутствие спецсимволов.

### Пагинация:
- Каждая страница пагинации должна содержать тег canonical на саму себя.
- Использование тегов prev/next для корректного индексирования страниц.

### Sitemap:
- Создание автоматического sitemap, который включает все страницы с актуальными данными о товарных группах и подкатегориях.

---

## 5. Интеграции и функциональные блоки

### 1. **Корзина:**
   - Возможность добавления товаров в корзину без перехода на страницу товара.
   - Поддержка промокодов с автоматическим пересчетом цены.

### 2. **Личный кабинет:**
   - Верификация данных пользователя через телефон (с помощью API).
   - История заказов, возвраты, возможность "повторить заказ".

### 3. **Платежи:**
   - Поддержка нескольких методов оплаты: карты, QR-коды, ERIP.
