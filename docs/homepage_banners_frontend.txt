Баннеры на главной — инструкция для фронта
==========================================

Эндпоинты
---------
GET /api/v1/homepage/slider/main          — главный слайдер
GET /api/v1/homepage/slider/horizontal    — широкий горизонтальный баннер
GET /api/v1/homepage/slider/advertising   — рекламные баннеры

Legacy (алиас horizontal):
GET /api/v1/homepage/slider/banners

Ответ: массив активных баннеров, отсортированных по position ASC
(внутри слота: desktop → tablet → mobile).

Поля attributes:
  - section     — "main" | "horizontal" | "advertising"
  - slot_key    — стабильный id визуального слота (общий для responsive-вариантов)
  - breakpoint  — "desktop" | "tablet" | "mobile" | "all" (all — legacy)
  - variant     — код размера
  - width       — ожидаемая ширина в px
  - height      — ожидаемая высота в px
  - position    — порядок слота в блоке
  - active      — всегда true в этом API
  - image_url   — URL картинки
  - link_url    — итоговая ссылка (custom_url или /categories/:ikea_id)
  - updated_at


Как выбирать картинку
---------------------
Один визуальный слайд = несколько записей с одним slot_key.
Группируй строго по slot_key и выбирай по breakpoint:

  Breakpoint | Main                         | Horizontal                     | Advertising
  -----------|------------------------------|--------------------------------|------------------------------------------
  desktop    | main_1500x516  (1500×516)    | horizontal_1500x256 (1500×256) | advertising_742x256        (742×256)
  tablet     | main_960x516   (960×516)     | horizontal_960x256  (960×256)  | advertising_960x256        (960×256)
  mobile     | main_572x594   (572×594)     | horizontal_742x256  (742×256)  | advertising_mobile_960x256 (960×256)

Advertising раскладка:
  desktop: по 2 баннера (слота) 742×256 в ряд;
  tablet / mobile: по 1 баннеру 960×256.
Не склеивайте два advertising-слота в одну API-запись.

Фоллбек, если нужного размера нет:
  tablet → desktop → mobile (что есть в ответе по slot_key).
Для advertising mobile↔tablet размеры одинаковые (960×256) — можно фоллбечить друг в друга.

Клик: переход на link_url.


Админка
-------
Раздел: «Баннеры на главной» (/admin/home_banners)

Scopes:
  - Главный слайдер
  - Горизонтальный баннер
  - Рекламные баннеры

На каждый слот (включая advertising) создайте 3 записи
(desktop/tablet/mobile) с одинаковым slot_key, position и ссылкой.

Advertising размеры в админке:
  - 742×256 (desktop, 2 в ряд)
  - 960×256 (планшет)
  - 960×256 (mobile)

Важно:
  - Текст/кнопка на баннере зашиты в картинку
  - description в админке — только служебные заметки
