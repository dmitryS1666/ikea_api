Баннеры на главной — инструкция для фронта
==========================================

Эндпоинты
---------
GET /api/v1/homepage/slider/main      — главный слайдер
GET /api/v1/homepage/slider/banners   — горизонтальный баннер

Ответ: массив баннеров (активные, отсортированы по position).

Поля attributes у баннера:
  - section     — "main" | "secondary"
  - variant     — код размера (см. таблицу ниже)
  - width       — ожидаемая ширина в px
  - height      — ожидаемая высота в px
  - position    — порядок в слайдере
  - active      — всегда true в этом API
  - image_url   — URL картинки
  - link_url    — итоговая ссылка (категория или custom_url)


Как выбирать картинку по разрешению
-----------------------------------
Один визуальный слот = несколько записей с разными размерами
(одна и та же ссылка, разные variant / width).

Группируй баннеры одного слота (например по link_url + position)
и выбирай картинку под текущий breakpoint:

  Breakpoint | Main (слайдер)              | Secondary (горизонтальный)
  -----------|-----------------------------|---------------------------
  Desktop    | main_1500x516  (1500×516)   | secondary_1500x256 (1500×256)
  Tablet     | main_960x516   (960×516)    | secondary_960x256  (960×256)
  Mobile     | main_572x594   (572×594)    | secondary_742x256  (742×256)

Рекомендация: ориентируйся на width / height, а не парси имя variant.

Фоллбек, если нужного размера нет:
  tablet → desktop → mobile (что есть в ответе).

Клик по баннеру: переход на link_url.


Настройка в админке
-------------------
Раздел: «Слайдер на главной» (/admin/home_banners)

На каждый слот создай 3 баннера — desktop / планшет / mobile:

  1. Секция: «Главный баннер» или «Горизонтальный баннер»
  2. Вариант размера — нужный breakpoint
  3. Картинка строго под размер выбранного варианта
  4. Ссылка: категория ИЛИ кастомный URL
  5. Одинаковый position у трёх размеров одного слота
  6. Галочка «Активен»

Важно:
  - Текст/кнопка на баннере зашиты в картинку
    (отдельных полей title / subtitle / button_text в API нет)
  - description в админке — только служебные заметки, на фронт не отдаётся
