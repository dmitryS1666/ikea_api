2025-01-07

- **Всего:** 537 категорий
- **Числовые ID:** 509 (94.8%)

- **Другие форматы:** 28 (5.2%)

- **Без URL:** 0

5. `48988` - AGD do SUNNERSTA - `/pl/pl/cat/agd-do-sunnersta-48988/`

## Анализ причин

### Причина 1: HTML парсинг не находит продукты (ВЕРОЯТНО ОСНОВНАЯ)

**Обоснование:**
- Все 537 категорий имеют URL, что означает возможность HTML парсинга
- Текущий парсер может не находить продукты из-за:
  - Изменений в структуре HTML страниц IKEA
  - Динамической загрузки продуктов через JavaScript
  - Новых форматов данных (JSON в других местах)
  - Изменений в селекторах CSS

**Решение:** ✅ **РЕАЛИЗОВАНО**
- Улучшен `CategoryProductsFetcher` с новыми паттернами поиска
- Добавлен поиск в `<script type="application/json">`
- Добавлен поиск в window переменных (`__IKEA_PRODUCTS__`, `__PRODUCTS__`)
- Добавлен поиск через data-атрибуты
- Добавлен поиск через ссылки на продукты
- Расширен список селекторов для HTML элементов

### Причина 2: API по ID не возвращает продукты

**Обоснование:**
- 509 категорий имеют числовые ID, которые должны работать через API
- Возможные причины:
  - ID не валидны для API
  - API требует другие параметры
  - Категории действительно не имеют продуктов в системе IKEA
  - API блокирует запросы

**Решение:** ✅ **РЕАЛИЗОВАНО**
- HTML парсинг имеет приоритет 1 (все категории имеют URL)
- API по ID используется как приоритет 2
- Добавлено детальное логирование для отладки

### Причина 3: Категории-контейнеры

**Обоснование:**
- Некоторые категории могут быть контейнерами для подкатегорий
- Продукты могут находиться в дочерних категориях

**Решение:** ✅ **РЕАЛИЗОВАНО**
- Добавлена стратегия поиска через дочерние категории
- Рекурсивный поиск в подкатегориях
- Автоматическое использование для категорий с детьми

## Реализованные решения

## SQL запросы для мониторинга

### Проверка категорий без продуктов:
```sql
SELECT 
  c.ikea_id,
  c.name,
  c.url,
  (SELECT COUNT(*) FROM categories WHERE parent_ids::text LIKE '%"' || c.ikea_id || '"%') as children_count
FROM categories c
LEFT JOIN products p ON p.category_id = c.ikea_id
WHERE p.id IS NULL 
  AND (c.is_deleted IS NULL OR c.is_deleted = false)
ORDER BY c.name;
```

### Проверка эффективности поиска:
```sql
-- Категории, которые получили продукты после улучшений
SELECT 
  c.ikea_id,
  c.name,
  COUNT(p.id) as products_count,
  MAX(p.updated_at) as last_product_update
FROM categories c
INNER JOIN products p ON p.category_id = c.ikea_id
WHERE c.ikea_id IN (
  -- ID категорий, которые были без продуктов
  SELECT ikea_id FROM categories 
  WHERE ikea_id IN ('700403', '50374', '50382', '700535', '48988')
)
GROUP BY c.ikea_id, c.name;
```
