## Причины отсутствия продуктов

### Причина 1: HTML парсинг не находит продукты (ВЕРОЯТНО ОСНОВНАЯ)

**Почему это вероятно:**
- Все категории имеют URL
- Нет дочерних категорий
- Это означает, что проблема в парсинге HTML

**Возможные подпричины:**
1. Продукты загружаются динамически через JavaScript
2. Структура HTML изменилась
3. Продукты находятся в новых форматах данных
4. Требуется авторизация или обход защиты

**Решение:** ✅ **ЧАСТИЧНО РЕАЛИЗОВАНО**
- Улучшен CategoryProductsFetcher с новыми паттернами
- Нужно добавить headless browser для JS-рендеринг

### Причина 2: Категории действительно пустые

**Почему это возможно:**
- В системе IKEA может не быть продуктов для этих категорий
- Категории могут быть для будущих продуктов
- Категории могут быть устаревшими

**Решение:**
- Проверить реальные страницы категорий в браузере
- Если продуктов нет на сайте - категории действительно пустые

### Причина 3: API по ID не работает

**Почему это возможно:**
- ID категорий могут быть не валидны для API
- API может требовать другие параметры
- API может блокировать запросы

**Решение:** ✅ **РЕАЛИЗОВАНО**
- HTML парсинг имеет приоритет 1
- API используется как fallback
