# Как вручную завести SEO-страницу каталога

> Раздел админки: **Каталог → SEO-страницы каталога**  
> URL на сайте: `/catalog/seo/<slug>`

---

## Что это

SEO-страница — готовая посадочная под конкретный запрос: заголовок, мета-теги, подборка товаров и SEO-текст внизу. Товары подтягиваются автоматически по правилам, которые вы задаёте в JSON.

---

## Порядок работы

### Шаг 1. Создать запись

1. Откройте **Каталог → SEO-страницы каталога**.
2. Нажмите **Новая запись**.
3. Заполните вкладку **«Основное»**:

| Поле | Что писать |
|------|------------|
| **Внутреннее название** | Для себя, например: `Диваны до 1000 BYN` |
| **Slug** | Часть URL латиницей: `divany-do-1000-byn` |
| **H1** | Заголовок на странице: `Диваны до 1000 BYN` |
| **Статус** | Пока оставьте **Черновик** |
| **Indexable** | ✓ — если страница должна индексироваться |
| **Позиция** | Порядок в списках (0, 10, 20…) |
| **Canonical path** | Обычно **не трогать** |

**Правила для slug:**
- только латиница, цифры и дефисы;
- без пробелов, кириллицы и спецсимволов;
- примеры: `belye-shkafy-pax`, `divany-do-1000-byn`.

---

### Шаг 2. Заполнить SEO

Вкладка **«SEO»**:

| Поле | Рекомендация |
|------|--------------|
| **Meta title** | До **90** символов. Пример: `Диваны до 1000 BYN — купить с доставкой` |
| **Meta description** | До **220** символов. Кратко: что на странице и зачем заходить |
| **SEO-текст** | Текст внизу страницы. Можно с заголовками и списками |

---

### Шаг 3. Настроить подборку товаров

Вкладка **«Фильтры / подборка»** → поле **filter_config JSON**.

Скопируйте шаблон и подставьте свои значения:

```json
{
  "category_ids": ["fb001"],
  "max_price": 1000,
  "filters": {
    "f-series": ["PAX"]
  },
  "only_available": true,
  "sort": "popular",
  "limit": 60
}
```

**Что означают поля:**

| Поле | Обязательно | Описание |
|------|-------------|----------|
| `category_ids` | Желательно | ID категорий IKEA (`ikea_id`). В подборку попадут товары из категории и всех вложенных |
| `min_price` | Нет | Минимальная цена в BYN |
| `max_price` | Нет | Максимальная цена в BYN |
| `filters` | Нет | Только коллекция и/или ценовые корзины (см. ниже) |
| `only_available` | Нет | `true` — только товары в наличии |
| `sort` | Нет | Сортировка (см. таблицу ниже). По умолчанию: `popular` |
| `limit` | Нет | Сколько товаров взять (от 1 до 240, по умолчанию 60) |

**Допустимые значения `sort`:**

| Значение | Поведение |
|----------|-----------|
| `popular` | По популярности (по умолчанию) |
| `cheapest` | Сначала дешевле |
| `expensive` | Сначала дороже |
| `newest` | Сначала новые |
| `relevance` | По релевантности поиска |

> Не используйте `price_asc` / `price_desc` — они не поддерживаются и сортировка сработает некорректно.

**Фильтры — что писать в `filters`:**

| Ключ | Что фильтрует | Можно писать короче |
|------|---------------|---------------------|
| `f-series` | Коллекция | `series` или `collection` |
| `f-price-buckets` | Ценовая корзина | — |

> Цвет, материал, размер и другие фильтры витрины **не поддерживаются** на SEO-страницах. Используйте `category_ids`, `min_price` / `max_price` и при необходимости `f-series`.

Значения `f-series` и `f-price-buckets` — id из `available_filters` категории на витрине.

**Где взять `ikea_id` категории:**  
Откройте нужную категорию в админке (**Категории**) — `ikea_id` указан в карточке.

---

### Шаг 4. Сохранить черновик

Нажмите **Создать** (или **Обновить**).

**Что обязательно для черновика:**
- **Slug** — единственное поле, без которого запись не сохранится.

**Что можно заполнить позже (до публикации):**
- H1, Meta title, Meta description
- `filter_config` (пустой `{}` для черновика допустим)

Пока страница не сохранена, кнопка генерации подборки недоступна.

---

### Шаг 5. Сгенерировать подборку

В правой колонке (**Подборка**):

1. Нажмите **«Сгенерировать snapshot товаров и фильтров»**.
2. Подождите 5–10 секунд.
3. Обновите страницу (F5).

Проверьте:
- **Товаров** — должно быть **больше 0**;
- **Фильтров** — сколько фильтров доступно на странице;
- **Последняя генерация** — время обновилось.

Если **Товаров = 0** — подборка пустая. Не публикуйте, пока не исправите `filter_config` (см. раздел «Частые ошибки»).

---

### Шаг 6. Проверить на сайте

В правой колонке нажмите **«Открыть frontend»**.

Убедитесь, что:
- заголовок H1 отображается верно;
- товары на месте;
- SEO-текст внизу читается нормально.

---

### Шаг 7. Опубликовать

1. Вернитесь в админку.
2. **Статус** → **Опубликовано**.
3. **Indexable** — ✓ (если нужна индексация).
4. Сохраните.

> Для публикации обязательны: **H1**, **Meta title**, **Meta description** и непустой **filter_config**.

---

## Примеры готовых страниц

### Только по цене, без категории

```json
{
  "max_price": 500,
  "only_available": true,
  "sort": "popular",
  "limit": 60
}
```

### Категория + коллекция

```json
{
  "category_ids": ["st001"],
  "filters": {
    "series": ["PAX"]
  },
  "only_available": true,
  "sort": "popular",
  "limit": 60
}
```

### Категория + ценовой диапазон

```json
{
  "category_ids": ["bm001"],
  "min_price": 200,
  "max_price": 1500,
  "only_available": true,
  "sort": "cheapest",
  "limit": 120
}
```

---

## Чеклист перед публикацией

- [ ] Slug латиницей, понятный и уникальный
- [ ] H1, Meta title, Meta description заполнены
- [ ] `filter_config` — валидный JSON (проверьте скобки и запятые)
- [ ] Snapshot сгенерирован, **Товаров > 0**
- [ ] Страница проверена через **«Открыть frontend»**
- [ ] **Indexable** включён (если нужна индексация)
- [ ] Статус → **Опубликовано**

---

## Когда страница не попадёт в поиск

| Ситуация | Что происходит |
|----------|----------------|
| Статус **Черновик** или **Архив** | Страница не видна на сайте |
| **Товаров = 0** | Предупреждение в админке, `indexable` сбрасывается, в sitemap не попадает |
| **Indexable** выключен | Страница на сайте есть, но в sitemap не попадает |

---

## Частые ошибки

| Проблема | Что сделать |
|----------|-------------|
| Не сохраняется при публикации | Заполните H1, meta title, meta description и непустой `filter_config` |
| Meta title / description слишком длинные | Не больше 90 и 220 символов соответственно |
| Slug уже занят | Выберите другой slug — каждый должен быть уникальным |
| Ошибка JSON | Проверьте кавычки, запятые, закрывающие скобки. Валидатор: jsonlint.com |
| 0 товаров | Проверьте `ikea_id` категории, `min_price` / `max_price`, `only_available`, id коллекции (`f-series`) |
| Неверный slug | Только `a-z`, цифры, дефис. Без пробелов и кириллицы |
| Неверная сортировка | Используйте `popular`, `cheapest`, `expensive`, `newest` или `relevance` |
| Старые цены/остатки | Нажмите **Сгенерировать snapshot** ещё раз (или дождитесь ночного автообновления) |

---

## Обновление уже опубликованной страницы

1. Измените нужные поля (SEO, filter_config, slug).
2. Если меняли **filter_config** — снова нажмите **Сгенерировать snapshot**.
3. Проверьте на фронте.
4. Сохраните.

Подборки у **опубликованных** страниц также обновляются автоматически после синхронизации цен и остатков.

---

## Краткая шпаргалка

```
1. Создать → заполнить Основное + SEO + filter_config
2. Сохранить как Черновик
3. Сгенерировать snapshot → проверить, что товаров > 0
4. Открыть frontend → визуально проверить
5. Статус → Опубликовано
```
